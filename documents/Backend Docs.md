# Register

Lehetővé teszi hogy regisztráljunk új felhasználókat.
Minden mező kitöltése kötelező. A weboldal email címet és jelszavát kér a felhasználótól.


# Login

Lehetővé teszi hogy a felhasználó bejelentkezzen.
A mezőbe a beregisztrált emailcímet és jelszót kel be írni.


# Logout

Lehetővé teszi a felhasználó kijelentkezését.


# Change Password

Lehetővé teszi hogy a felhasználó megváltoztassa a jelszavát.
A mezőbe új jelszót kell majd megadni nem lehet üresen hagyni.


# Current User Profile
Betölti az adatbázisból az adatokat.


# Modify Profile

Lehetővé teszi a felhasználónak hogy módosítsa a profilját.


# Product List / Search / Filter

A Product List segítségével meg nézhetjük a termékek listáját.
A Search-el rá kereshetünk bizonyos termékekre.  
A Filter segít abban hogy ki szűrjünk a termékek kategóriáját.


# Product Details

A termékekről ad pontos információt.


# Cart

A Cart lehetővé teszi hogy meg nézzük a Termékeket el tárolva a Cart-ba.


# Add to Cart

Hozzá adja a Cart-ba a kiválasztott terméket.


# Remove from Cart

Eltávolítja a kiválasztott terméket a Cart-ból.


# Change quantity

Lehetővé teszi hogy ki válaszuk hogy mennyit szeretnénk az adott termékből. 


# Track Orders

Megmutatja hogy hol jár a megrendelés.
Tudatja velünk hogy mennyi időn belül jön meg a rendelés.


# Place Orders
Rendelés leadást tesz lehetővé az oldalon utánvétes fizetési opcióval.


# Cancel Orders

Vissza vonja a rendelést.


# Order Details

Megejelenití a megrendelés információit (mennyibe kerül, mit vettünk, hova hozzák ki).


# Modify shipping information

Beállíthatjuk a szálitás adatait (cím, hogy milyen gyorsan szállítsák ki).
